# Dashboard sul settore dell'istruzione

Dashboard interattiva in Looker Studio su 92 paesi:
- KPI: studenti uomini, studenti donne e studenti internazionali;
- distribuzione geografica per genere e top 10 paesi;
- tabella riepilogativa per paese, filtrabile;
- ranking delle università.
