# Analisi del mercato del vino

**Obiettivo:** capire il mercato del vino partendo dal dataset `winemag-data-130k-v2.csv` (circa 130.000 recensioni) e proporre un listino.

- **Preparazione dei dati:** rimozione dei duplicati, gestione dei valori nulli (per esempio il prezzo) ed eliminazione delle colonne superflue.
- **Analisi esplorativa:** distribuzione di punteggi e prezzi, paesi e regioni (grafico sunburst), varietà e produttori.
- **Insight:** correlazione positiva tra prezzo e punteggio: oltre una certa fascia di prezzo diventa raro trovare vini sotto la media.
- **Proposta:** listino segmentato in tre fasce, Premium, Best Value ed Emerging.

📓 Notebook: [`GiovanniLettieriPython.ipynb`](../GiovanniLettieriPython.ipynb) · 📄 [Presentazione](presentazione.pdf)

**Strumenti:** Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, Jupyter.
