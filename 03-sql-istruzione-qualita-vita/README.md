# L'impatto dell'istruzione sulla qualità della vita

**Domanda:** un alto accesso all'istruzione primaria e terziaria migliora lavoro, salute, ricchezza e sostenibilità di un paese?

- **Dati:** *Global Country Information Dataset 2023* e *Global Data on Sustainable Energy* ([`dati/`](dati/)).
- **Preparazione:** pulizia in Google Sheets, tabelle create in MySQL con colonne tradotte in italiano, import con Beekeeper Studio e query di controllo per verificare coerenza e integrità.
- **Analisi:** confronto tra paesi ad alta e bassa istruzione su disoccupazione, salario minimo, salute, PIL ed energia.
- **Esempio di insight:** nei paesi ad alta istruzione le emissioni di CO₂ risultano circa 5 volte maggiori, mentre quelli a bassa istruzione usano più energia rinnovabile.
- **Conclusione:** l'istruzione migliora la qualità della vita, ma solo se accompagnata da politiche mirate in ogni settore.
